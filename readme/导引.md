## 开发流程遵循
### 开发与提交流程
1. **Fork Gitee 项目**
2. **修改更新**
3. **完成后 Fetch 并 Pull**  
   检查主进度是否有最新并拉取处理合并。
4. **推送开发分支**（如果有）
5. **推送 Fork 的 master 分支**
6. **在 Fork 仓库提交 master 对源仓库的 PR**
7. **审核人员**  
   Clone 该 Fork 仓库到本地审查测试。
8. **审查过程**
    - 无问题则勾选通过测试，并标记为审查通过。
    - 有问题则打回，重新修改。
9. **处理合并**
    - 合并人员检查并手动处理合并。
    - 完成后 PR 自动更新为已合并表示结束。
10. **更新完成**
